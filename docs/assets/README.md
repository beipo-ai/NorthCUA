# Documentation artwork

The three mechanism illustrations are rendered from the unchanged **31 October
2026, 123-page NorthCUA Technical Report** distributed in [paper/main.pdf](../paper/main.pdf).
They show the lifecycle (Figure 4, page 8), long-horizon context (Figure 5,
page 11) and outcome evaluation (Figure 7, page 15).

[manifest.json](manifest.json) records report/figure identities, render provenance
and output checksums. GUI scenes, action trajectories and judgments in these
figures are schematic; they are **not recorded agent runs** or execution evidence.
The previews preserve the report's content and labels, at documentation resolution.

The [brand assets](brand/README.md) use the exact paper mark and outlined lettering.
The [recorded demo assets](demos/manifest.json) have their own provenance and evidence
boundary in the [showcase guide](../showcase.md); do not label those as diagrams.
