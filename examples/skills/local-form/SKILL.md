# Complete the requested local form

Inspect the current page or screenshot. Identify required fields and the requested
values before entering them. Preserve unrelated page state. Submit once the
requested fields are complete, then inspect the visible confirmation in the same
session. If the task includes an expected receipt or saved output, compare it to
that expectation before reporting success. Report missing inputs or visible
validation errors instead of inventing values or assuming a click succeeded.
