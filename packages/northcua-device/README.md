# northcua-device

Part of the **NorthCUA Harness** distributed in the **NorthCUA** project.

Device worker for native Desktop and Web commands. It depends on the matching root package, which supplies the runtime bridge.

Install the four matching release wheels together. See the root
[installation guide](../../docs/getting-started.md), [execution modes](../../docs/running.md)
and [Apache-2.0 license](LICENSE).
